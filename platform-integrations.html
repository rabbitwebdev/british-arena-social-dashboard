    Open Meta for Developers

    One-time setup for the platform owner

    1. Create or open one Business Meta developer app for the Social Dashboard. Use a staging app for testing.
    2. Enable the Facebook Login for Business capability and the Page/Instagram permissions used by this dashboard.
    3. In the Facebook Login settings, add the exact callback URL above to Valid OAuth Redirect URIs.
    4. Copy the App ID and App Secret from App settings → Basic into the staging service's Railway Variables as META_APP_ID and META_APP_SECRET. Do not paste secrets into this page or GitHub.
    5. Redeploy staging, then connect a Facebook Page you administer from Companies. Instagram discovery currently requires a linked professional Instagram account.
    6. Before public customers connect, complete Meta's required App Review/Advanced Access and any business verification requirements.

    This page only checks whether configuration is present. It does not validate Meta's approval status or test an access token. A connected account may need new permission if Meta revokes access.
